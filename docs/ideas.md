# 앱 아이디어 백로그

팀 슬랙에서 나온 차량용 앱 아이디어입니다. 기획할 때 [pleos-sdk-data.md](pleos-sdk-data.md)의 SDK·데이터와 대조해 구현 가능성을 확인하세요.

1. 안전점수가 낮은 차가 근처에 있을 때 알려주기
2. 졸음운전 위험일 때 깨워주기
3. 차에 에어드롭 보내기
4. 사람별 공조 설정 저장 (개인화 앱)
5. 시간·요일별 기본 목적지 설정
6. 가성비 주유소 찾아주기

자동주차 서드파티 앱과 그 스레드에서 나온 아이디어는 [third-party-ideas.md](third-party-ideas.md)에 기반 데이터로 보관합니다.
