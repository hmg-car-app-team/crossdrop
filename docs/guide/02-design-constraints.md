# 설계 제약

출처: Pleos 앱 기획 가이드(하드웨어 접근, API 호환성, 주행 규제, 주의분산, 보안), 앱 심사 가이드, 프로젝트 생성 문서, 설명회.

## SDK 사용 조건

| 구분 | 일반 개발 (Playground) | 공모전 |
|---|---|---|
| 신청 | Vehicle State·NaviHelper만 바로 사용. FusedLocation·TTS·STT·Vehicle Control은 "준비 중" | 신청 없이 매니페스트 선언만으로 사용 (설명회 32:29) |
| 비공개 SDK | - | 전부 제공 예정 (설명회 26:01) |
| App Market | Vehicle SDK 권한은 사전 협의·승인된 것만 선언 가능 | 수상 후 탑재 시 적용 |

## 주행 중 제한

DO를 선언하지 않은 앱은 주차 중에만 쓸 수 있습니다. DO를 선언한 앱도 `CarUxRestrictionsManager`의 `ActiveRestrictions`에 따라 기능을 직접 줄여야 하고, Vehicle SDK는 `ERROR_DRIVING_RESTRICTED`를 돌려줄 수 있습니다. 한국용 표는 없어서 "그외 지역"이 적용될 것으로 보입니다(추정).

| 주행 중 기능 | 북미 | 유럽 | 그외 지역 |
|---|---|---|---|
| 키보드, 다이얼패드 | ⛔ | ✅ | ✅ |
| 인포테인먼트 통합 검색 | 음성만 | ✅ | ✅ |
| 미디어 앱 로그인·설정·검색 | ⛔ | ⛔ | ✅ |
| 디지털키·도어·시트·차량 설정 | ⛔ | ⛔ | ⛔ |
| 동영상, QR 로그인, 매뉴얼(대용량 텍스트) | ⛔ | ⛔ | ⛔ |
| 내비게이션 검색 | ⛔ | ✅ | ✅ |

동영상·게임·브라우저 앱은 정차 중에만 쓸 수 있고 헤드업 알림을 쓸 수 없습니다. 주행 중 입력은 음성·프리셋·최근 항목을 우선하고, 큰 터치 영역과 단순한 메뉴를 씁니다.

## SDK로 얻을 수 없는 데이터

| 데이터 | 상태 |
|---|---|
| 차량 속도 | Vehicle SDK·FusedLocation에 없음. Android 표준 `CarPropertyManager`(`PERF_VEHICLE_SPEED`) 경로는 확인 필요 |
| 주변 차량, 카메라, 졸음·시선 감지 | 없음 |
| 운전자 식별 | 없음. 좌석별 착석 여부만 있음 |
| 계기판 경고등, 타이어 공기압 | `PRIVATE_CAR_SAFETY`(시스템 앱 권한) 필요 |
| 장기 운행 이력 | 없음. 트립·누적 값만 있어 앱이 직접 저장해야 함 |
| Vehicle Data API | 유럽 한정 |

## 그 밖의 정책

- 하드웨어 직접 접근 불가. 전화, SMS, 일부 센서, 캘린더, 주소록 API는 제한될 수 있습니다.
- 주행 중 네트워크 끊김에 대비해 캐싱, 재시도, 오프라인 안내 UI를 넣습니다.
- 호환성: Vehicle SDK와 FusedLocation은 차종마다 다르니 `check…Capabilities`, `isSupported()`로 확인합니다. NaviHelper는 내비 탑재 차량, TTS·STT는 전체 호환입니다.
- 개인정보: 수집 이유를 밝히고 명시적 동의 버튼으로만 동의를 받습니다. 토큰은 Keystore에 두고, 차량 밖으로 보내는 ID는 가명화하며, 운전 행동 데이터를 마케팅에 쓰지 않습니다.
