## 02장 기획서 작성 항목

fork한 프로젝트의 `planning/`에 이 항목대로 초안을 쓰면 됩니다. 분량 제한은 없습니다.

1. 앱 한 줄 소개: 앱을 한 문장으로
2. 기획 배경: 어떤 고객 니즈나 불편한 순간에 주목했고 왜 해결이 필요한지
3. 주요 기능 및 차량 특화 요소: 핵심 기능, 해결하는 문제, 차량에서 주는 새로운 경험
4. 주요 사용 시나리오: 누가, 어떤 상황에서, 어떻게 쓰는지 이용 흐름
5. 개발 계획: Pleos Connect 환경의 구현 범위와 SDK/API 사용 계획
6. 기대효과 및 발전 가능성: 사용자 가치, 타깃 고객 분석, 예상 MAU, Retention Rate, 서비스 확대 계획
7. 참고자료 (선택, 가산점): 앱 화면 시안, 시연 영상, GitHub 저장소
8. 숏폼 링크 (선택, 가산점 없음): 특별상용 세로 영상 링크

- 주민등록번호·신분증·상세주소는 요구하지 않습니다.
